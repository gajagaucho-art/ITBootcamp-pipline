# IT-Bootcamp---Data-pipeline


Pipline povezuje više koraka obrade u jedan automatski tok, gde izlaz jednog koraka postaje ulaz za sledeći.
Umesto da ručno pokrećeš svaku funkciju posebno i čuvaš međurezultate, pipeline spaja sve u jednu celinu. U zavisnosti od oblasti, koristi se za tri glavne stvari
1. Mašinsko učenje (Scikit-learn)
2. Obrada podataka (ETL i Data Engineering)
3. Obrada teksta i NLP (Hugging Face)
